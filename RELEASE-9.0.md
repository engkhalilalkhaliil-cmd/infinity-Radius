# InfinityNet ISP Ultimate 9.0

**Developer:** Khalil Al Khalil / خليل الخليل

## Platform scope
AAA/RADIUS, PPPoE, MikroTik RouterOS REST integration, OLT/ONU inventory, topology, NOC monitoring, billing, payments abstraction, reseller operations, CRM/customer 360, technician jobs, customer portal, mobile-ready APIs, webhooks, security events, encrypted network credentials, Prometheus/Grafana, backup automation and multi-tenant foundations.

## Important
Hardware-specific OLT provisioning and payment-provider settlement remain adapter integrations: each vendor/provider requires its API/credentials and must be validated on a staging network before production.
